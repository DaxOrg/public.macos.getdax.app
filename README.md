# Dax — public update feed

Hosts the Sparkle **appcast** and notarized release binaries (`Dax.zip`, `Dax.dmg`)
for [Dax](https://getdax.app). The app source is private; this repo exists so the
in-app updater can fetch updates without authentication.

- Appcast: `appcast.xml` on `main`
- Binaries: attached to each `v*` GitHub release
