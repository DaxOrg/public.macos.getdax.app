# public.macos.getdax.app

## About this project

This is the **public distribution repository** for the Dax macOS application. It hosts the Sparkle appcast feed and release binaries — the actual source code lives in the private `macos.getdax.app` repo.

## What this repo contains

- `appcast.xml` — Sparkle update feed consumed by the Dax app's built-in updater
- GitHub Releases — Notarized `.zip` and `.dmg` binaries attached to version tags (`v*`)

## Tech stack

- **Update framework:** Sparkle (EdDSA-signed appcast)
- **Minimum macOS:** 14.0
- **Distribution:** GitHub Releases

## How it works

1. The Dax app periodically fetches `appcast.xml` from this repo's `main` branch
2. The XML contains version metadata, download URLs, and Ed25519 signatures
3. Users are notified of updates and can download the latest binary
4. Binaries are hosted on GitHub Releases infrastructure

## Important notes

- This repo has no build system — it is purely a distribution channel
- Never modify `appcast.xml` by hand; it is generated by the release pipeline in `macos.getdax.app`
- Release binaries are signed with a Developer ID certificate and notarized by Apple
- The repo is public so the app can check for updates without authentication
